# 🦖 恐龙生存游戏

## 在线玩（点这个链接）

👉 **https://original-fires-resolve-wins.trycloudflare.com/play.html**

- 用 **Chrome 浏览器** 打开
- **不要用微信**
- 等 10 秒，看到绿色草地和 3D 恐龙就成功了

---

## 下载玩（最稳定，推荐）

1. 下载：**https://github.com/EKW2015/game/raw/main/play.html**
2. 确认文件约 **700KB**
3. **双击** `play.html` 打开（Windows 也可双击 `打开游戏.bat`）
4. 必须用 **Chrome**

---

## 操作

- 方向键 / WASD：移动
- 空格：咬击
- 吃比自己小的恐龙会变大进化

---
