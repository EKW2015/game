# 🏎️ 夜城飞车 NIGHT CITY RACING

霓虹城市里的 3D 竞速游戏，**打开网页就能玩**，不用安装、不用联网。

## 在线玩

👉 **https://ekw2015.github.io/game/racing.html**

用 **Chrome 浏览器** 打开（不要用微信内置浏览器）。

## 下载玩（最稳定）

1. 下载 **https://github.com/EKW2015/game/raw/main/racing.html**（约 800KB，3D 引擎已内置）
2. **双击** `racing.html`（Windows 也可以双击 `打开赛车游戏.bat`）

## 玩什么

| 模式 | 内容 |
| --- | --- |
| 赛事 | 16 场比赛，3 条赛道，对手越往后越强，拿名次赚金币解锁下一场 |
| 挑战 | 5 个挑战（3 条赛道计时赛 + 漂移大师 + 特技表演），可无限重复刷钱 |
| 自由驾驶 | 开阔场地里到处跳台，滞空和翻转都算特技分，退出时结算成金币 |
| 车库 | 10 台车可买，引擎 / 刹车 / 操控 / 涡轮 / 氮气瓶各 5 级改装，还能换车漆和轮毂 |
| 双人分屏 | 同一台电脑上下分屏对战，外加 3 名电脑车手 |

金币、改装、赛事进度都会自动存在浏览器里。

## 操作

**单人**

| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 油门、转向、刹车（停住后继续按是倒车） |
| Shift | 氮气加速 NOS |
| 空格 | 手刹漂移 |
| R | 回到赛道 |
| T | 回头看 |
| C | 切换视角（第三人称 / 远景 / 引擎盖 / 第一人称 / 俯视） |
| P 或 Esc | 暂停 |
| N | 静音 |

**双人分屏**：玩家 1 用方向键 + `M` 氮气 / `O` 回位 / `L` 回头 / `K` 视角；玩家 2 用 WASD + `Shift` 氮气 / `R` 回位 / `T` 回头 / `C` 视角。

手机上会出现触摸按键，但方向盘手感还是电脑键盘更好。

## 小技巧

- 弯前松油门、进弯点手刹，漂移能刷分也能过弯更快
- 漂移时氮气回充更快，出弯直道直接放氮气
- 缺钱就去刷挑战，攒够钱先升引擎和操控

## 开发

```bash
npm test          # 无头模拟：赛道、物理、AI、圈数名次、平衡与存档
npm run build     # 生成单文件 racing.html 和 docs/racing.html
```

源码在 `racing/`，逻辑与渲染分离：

| 文件 | 作用 |
| --- | --- |
| `racing/js/track.js` | 赛道样条采样、投影、曲率、发车位（纯数学） |
| `racing/js/car.js` | 街机车辆物理：前后/横向速度分解、漂移、氮气、跳跃 |
| `racing/js/world.js` | 路面与护栏规则、自由驾驶场地跳台高度 |
| `racing/js/ai.js` | 电脑车手：理想线、弯前减速、直道氮气、避让 |
| `racing/js/garage.js` | 车型目录、改装数值、金币与存档 |
| `racing/js/game.js` | 倒计时、圈数名次、漂移/特技计分、奖金结算 |
| `racing/js/scene.js` | Three.js 夜城场景、车库展台、五种相机 |
| `racing/js/carmodel.js` | 程序化生成的低多边形超跑模型 |

`racing/index.html` 是分文件的开发版；`tools/build-racing.js` 把它连同 Three.js 打成单文件。
