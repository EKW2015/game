# 🦖 恐龙生存游戏

## 在线玩（点这个链接）

👉 **https://original-fires-resolve-wins.trycloudflare.com/play.html**

- 用 **Chrome 浏览器** 打开
- **不要用微信**
- 等 10 秒，看到绿色草地和 3D 恐龙就成功了

---

## 下载玩（最稳定，推荐）

1. 下载：**https://github.com/EKW2015/game/raw/main/play.html**
2. 确认文件约 **700KB**
3. **双击** `play.html` 打开（Windows 也可双击 `打开游戏.bat`）
4. 必须用 **Chrome**

## 🐍 贪吃蛇（新增）

单文件小游戏，双击就能玩，不用联网、不用装东西。

1. 下载：**https://github.com/EKW2015/game/raw/main/snake.html**
2. **双击** `snake.html` 打开（Windows 也可双击 `打开贪吃蛇.bat`）

操作：方向键 / WASD 转向，手机可直接滑动屏幕；空格暂停，R 重开，M 静音。
吃 🍎 加 10 分，🌟 金果加 50 分（会消失，要抢）。三种难度：简单可穿墙，普通和困难撞墙就结束。

---

## 操作

- 方向键 / WASD：移动
- 空格：咬击
- 吃比自己小的恐龙会变大进化
