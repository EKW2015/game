# 🐉 3D 斗罗大陆：圣龙神辉战队

## 直接玩（用 Chrome 打开下面这个链接）

打开后会立刻开战（陈凯威上场）。点地面走路，WASD 移动，空格或右下角「攻击」键出手。

不要用微信。不要点 GitHub 源码页。

如果链接失效，再下载这个文件，用 Chrome 双击打开：  
https://github.com/EKW2015/game/blob/cursor/douluo-3d-game-33ae/play.html  
（点右上角 Download raw file，约 800KB）

## 角色设定

- **武魂：** 光明圣龙
- **境界：** 七环魂帝 / 魂圣（黄、紫、紫、黑、黑、黑、红）
- **封号：** 随等级提升，可达封号斗罗【圣龙斗罗】
- **魂骨：** 九万年左臂骨、九万年右臂骨
- **领域：** 十万年·圣龙主迹领域（徽章版）

## 技能一览（按资料完整收录）

### 七大武魂魂技

1. **光明龙爪** — 金芒右爪，净化撕裂，克制黑暗
2. **圣龙之翼** — 光翼飞行、移速暴增，散射龙羽远程打击
3. **光明龙啸** — 龙吟声波，眩晕、失明并降低防御
4. **圣龙金身** — 金纹龙鳞甲，免伤、免疫控制，反弹冲击波
5. **光耀审判击** — 天降光明巨剑，单体穿透并灼烧生命
6. **追踪太阳神光** — 金色激光柱弯曲拐弯，自动追踪直至命中
7. **光明圣龙真身** — 化身百米圣龙，全属性 +300%，免伤，前六魂技零魂力消耗

### 七大自创魂技

1. **圣龙爆破拳** — 压缩光明魂力，命中后二次金色爆炸
2. **光影瞬步** — 光线折射瞬移，原地留下残影
3. **圣龙摆尾** — 金色龙尾横扫，把周围敌人抽飞
4. **光盾守护** — 身前张开太阳般耀眼的金盾
5. **光明龙针** — 细小金针封穴破防
6. **御剑术·光芒** — 金色飞剑空中穿梭斩击
7. **圣龙破天击** — 化作金龙冲天再砸向地面

### 魂骨与领域

- **九万年左臂骨【圣龙裂空爪】** — 远距金色龙爪刃，威力大
- **九万年右臂骨【太阳重力拳】** — 力量暴增，敌人瞬间沉重无法躲闪
- **十万年·圣龙主迹领域（徽章版）** — 方圆化为金色世界；无徽章敌人全属性 -50% 并受光明火焰灼烧；佩戴圣龙徽章者免疫领域伤害，获圣龙祝福（魂力持续恢复、全属性 +30%）

## 怎么变强

靠近并击败星斗大森林中的魂兽（暗魔邪神虎、暗金恐爪熊、泰坦巨猿等）。击杀后吸收魂环，提升魂力等级、生命与攻击，并向封号斗罗进阶。
