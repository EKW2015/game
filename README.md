# 恐龙生存竞技场

俯视角恐龙生存对战游戏。在竞技场中移动、捕食更小的恐龙、与体型相近的对手撕咬战斗，不断进化变大，成为最后一只存活的恐龙。

## 玩法

- **移动**：WASD 或方向键
- **撕咬**：空格 或 J（体型相近时战斗）
- **吞食**：体型明显大于对手时靠近即可吞食
- **进化**：幼龙 → 猎手 → 霸主 → 传说
- **胜利**：消灭所有其他恐龙，最后一只存活

## 运行

直接用浏览器打开 `index.html`，或本地起一个静态服务：

```bash
python3 -m http.server 8123
```

然后访问 http://localhost:8123

## 技术

- 原生 HTML5 Canvas，无第三方依赖
- Web Audio API 合成音效
- 本地存储记录胜场
