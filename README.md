## 🏎️ 霓虹夜城飙车 3D（新）

夜晚的霓虹都市，开着跑车在无限延伸的街道上狂飙：手刹甩尾攒氮气，穿过青色光门换取时间。

### 怎么打开（两种方式，都要用 Chrome）

**A. 直接在线玩（最省事）**

点 **https://raw.githack.com/EKW2015/game/main/racing.html** ，等几秒加载完就能开车。

**B. 下载到电脑上玩（最稳，断网也能玩）**

1. 打开 **https://github.com/EKW2015/game/blob/main/racing.html**
2. 点右上角的下载按钮（**Download raw file**，一个向下箭头的图标）
3. 存下来的 `racing.html` 约 750KB，**双击**它就能玩（Windows 也可双击 `打开赛车游戏.bat`）

手机上用 Chrome 打开方式 A，横屏会自动出现触屏按钮。**不要用微信内置浏览器**，它不支持 3D。

### 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `↑` | 油门 |
| `S` / `↓` | 刹车、倒车 |
| `A` `D` / `←` `→` | 转向 |
| `空格` | 手刹漂移 |
| `Shift` | 氮气加速 |
| `C` | 切换视角（跟车 / 远景 / 车内） |
| `T` | 按住回头看 |
| `R` | 卡住了就回到路面 |
| `P` | 暂停 |

手机横屏打开会自动出现触屏按钮。

### 四种模式

- **🏁 竞速赛**：和 4 个 AI 对手在环城赛道上跑 2 圈，按名次拿奖金。跟着屏幕顶部的绿色箭头和小地图上的黄色环线跑。拿到前三名会解锁更长更难的赛道。
- **⚡ 极速冲刺**：开环门点赛道，倒计时起步，一路冲到底。比用时拿金银铜牌（金牌 ≤ 目标时间，银/铜放宽到 1.25× / 1.5×）。超时作废；穿门会大幅回氮气。
- **⏱ 计时挑战**：60 秒起步，每穿过一个青色光门 +16 秒。光门位置看顶部箭头、小地图绿点，或者天上那道冲天光柱。
- **🌃 自由驾驶**：没有计时，飞跳台、甩尾、捡金币。

### 车库

金币可以买车和升级，四台车性能差别很大：

| 车 | 价格 | 特点 |
| --- | --- | --- |
| 街头轰鸣 | 免费 | 入门好开，转向听话 |
| 甩尾狂人 | 1500 | 抓地力低，专为漂移 |
| GT 猛兽 | 4000 | 推背感强，尾巴稳 |
| 超音速 | 9000 | 极速怪物，需要胆量 |

升级项：引擎（加速）、刹车（制动）、轮胎（抓地）、氮气（极速），每项 5 级。
**用免费车大概只能跑到第三名，换车升级之后才有能力争第一** —— 这就是赚钱的动力。

### 怎么赚金币

- 竞速赛名次奖金：第一名 1000，往后 600 / 350 / 180 / 90
- 极速冲刺奖牌奖金：金牌 800 / 银牌 450 / 铜牌 200
- 路上的金币：每枚 25
- 跳台腾空特技、漂移结算：都会折算成金币
- 计时挑战结束按得分折算

想看效果又懒得开车？打开 `racing/index.html#demo` 让 AI 自己开，加 `#demo-race` 看竞速、`#demo-sprint` 看冲刺。

## 开发

纯静态项目，没有依赖，改完源码重新打包即可：

```bash
node tools/build-racing.js   # racing/ -> racing.html + docs/racing.html
node tools/build-play.js     # js/ -> play.html
node tools/smoke-racing.js   # 赛车逻辑自测（物理 / 碰撞 / 计分）
node tools/smoke.js          # 恐龙游戏自测
```

赛车源码在 `racing/`，逻辑层和渲染层是分开的：

| 文件 | 职责 |
| --- | --- |
| `citymap.js` | 城市网格布局、建筑碰撞 |
| `ramps.js` | 跳台位置与坡面高度 |
| `cars.js` | 车型数据、升级项、金币存档 |
| `car.js` | 车辆物理（含腾空与落地） |
| `route.js` | 竞速环线与极速冲刺开环路线 |
| `autodrive.js` | 自动驾驶（AI 对手 / 演示 / 测试共用） |
| `racegame.js` | 四种模式的规则与计分 |
| `carmodel.js` | 车辆网格（轮廓挤出成型） |
| `city3d.js` | 夜城场景与贴图烘焙 |
| `rrender.js` | 相机、灯光、特效 |
| `rmain.js` | 输入、菜单、车库、HUD |

上面前 7 个文件都不依赖 THREE，所以物理、碰撞、AI、计分全都能在 Node 里直接跑测试。
