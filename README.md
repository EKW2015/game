# 🦖 无限恐龙世界 3D

真实 3D 恐龙 + 无限大地图 + 自由探索进化。

## 怎么玩

1. 下载 **play.html**（约 700KB）：https://github.com/EKW2015/game/blob/main/play.html
2. 用 **Chrome** 双击打开
3. 点 **进入世界**
4. **方向键** 移动，靠近小恐龙吞食，不断变大

## 特性

- **无限世界**：没有边界，一直走一直有新地形
- **真实 3D 恐龙**：T-Rex 风格模型（头、尾、腿、牙）
- **第三人称相机**：跟随你的恐龙
- **区块地形**：起伏草地、树木、岩石
- **进化系统**：幼龙 → 猎手 → 霸主 → 传说

## 操作

| 按键 | 作用 |
|------|------|
| 方向键 / WASD | 移动 |
| 空格 / J | 撕咬 |
| R | 重新开始 |
