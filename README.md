# 斗罗大陆 · 光明圣龙魂帝 3D

第三人称 3D 魂师对战：武魂**光明圣龙**，七环魂帝，含魂技、自创魂技、魂骨与圣龙领域。

## 在线玩

打开仓库 Pages 或本地 `play.html`（Chrome）。

## 本地

1. 双击 `play.html`，或双击 `打开游戏.bat`
2. 开发时用 `index.html`（需同时能加载 `js/` 与 `css/`）
3. 重新打包单文件：`node tools/build-play.js`

## 操作

- **WASD / 方向键**：移动（相对镜头）
- **鼠标点击画面**：锁定指针并转动视角
- **J / 左键**：普攻
- **空格**：跳跃；开启圣龙之翼后可滞空
- **1–7**：魂技
  1. 光明龙爪（克制黑暗）
  2. 圣龙之翼（加速、飞行、龙羽）
  3. 光明龙啸（眩晕 / 致盲 / 削防）
  4. 圣龙金身（减伤、抗控、反震）
  5. 光耀审判击（锁定光剑 + 灼烧）
  6. 追踪太阳神光（弯曲追踪）
  7. 光明圣龙真身（全属性 +300%，免疫，前六魂技无消耗）
- **Q** 光影瞬步 · **E** 圣龙爆破拳 · **R** 圣龙摆尾 · **F** 光盾守护
- **T** 光明龙针 · **Y** 御剑术·光芒 · **C** 圣龙破天击
- **Z** 圣龙裂空爪（九万年左臂骨）· **X** 太阳重力拳（九万年右臂骨）
- **V** 十万年·圣龙主迹领域（徽章友军祝福，其余属性 -50%；非光系持续光焰）

## 设定

- 称号：光明圣龙魂帝
- 魂环：黄、紫、紫、黑、黑、黑、红
- 友军佩戴**圣龙徽章**，领域内回魂力且属性 +30%
