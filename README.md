# 🎱 台球怎么打开

请用 **Chrome** 打开。不要用微信（会白屏）。

GitHub 上点 `pool.html` 只能看到代码，那不是游戏。

## 现在在线玩（点这个）

👉 **https://raw.githack.com/EKW2015/game/cursor/open-pool-game-925e/pool.html**

第一次可能要等几秒。看到绿色球桌就成功了。

## 下载玩（最稳）

1. 打开这个下载页：https://github.com/EKW2015/game/blob/cursor/open-pool-game-925e/pool.html
2. 点右上角 **Download raw file**（下载）
3. 用 **Chrome 双击** 打开下载下来的 `pool.html`
4. Windows 也可以双击 `打开台球.bat`

## 操作

- 按 **4** 开始闯关（推荐）
- 方向键 / WASD 瞄准和调力道
- **空格** 击打
- 过关按回车进下一关
- **M** 打开菜单
- 屏幕上还有大按钮，不用鼠标也能玩
