# 🦖 恐龙生存游戏

## 在线玩（点链接就行）

👉 **https://htmlpreview.github.io/?https://raw.githubusercontent.com/EKW2015/game/main/play.html**

- 用 **Chrome 浏览器** 打开（不要用微信）
- 等几秒，出现绿色草地和 3D 恐龙就成功了

---

## 下载玩（最稳定）

### 第 1 步：下载文件

👉 **https://github.com/EKW2015/game/raw/main/play.html**

- 电脑：浏览器打开后 **Ctrl+S 另存为**，或直接下载
- 手机：长按链接 → 下载

文件大小必须是 **约 700KB**（太小说明没下完，重新下载）

### 第 2 步：打开

- **Windows**：双击 `play.html`，或双击 `打开游戏.bat`
- **Mac**：右键 → 打开方式 → Chrome
- **必须用 Chrome**，不要用微信、不要用 GitHub 网页预览

---

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 空格 | 咬击 |
| 吃比自己小的恐龙 | 长大进化 |

---

## 打不开？对照检查

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 全白屏 | 用了微信或 GitHub 预览 | 换 Chrome 浏览器 |
| 链接没反应 | 网络问题 | 用上面「下载玩」方法 |
| 文件只有几 KB | 下载不完整 | 重新下载，确认约 700KB |
| 在线链接慢 | 首次加载大文件 | 等 10～20 秒 |
