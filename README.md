## ✅ 正确打开方法（选一个）

### 方法 1：下载后双击（推荐）

1. 打开：https://github.com/EKW2015/game/blob/main/play.html
2. 点右上角 **↓ Download raw file** 下载
3. 确认文件大小约 **700KB**（如果只有几十 KB 是旧版）
4. 用 **Chrome 浏览器** 双击 `play.html`
5. 应看到深绿色背景 + 「无限恐龙世界 3D」+ 3D 画面

### 方法 2：在线直接玩

用 Chrome 打开（如果链接可用）：

https://ekw2015.github.io/game/

（需在 GitHub 仓库 Settings → Pages 开启，选 docs 文件夹）
