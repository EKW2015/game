# 🦖 恐龙生存竞技场 3D

第三人称 3D 视角的恐龙生存对战游戏。

## 怎么玩（2 步）

### 第 1 步：下载

👉 打开网页，点 **Download raw file**：

**https://github.com/EKW2015/game/blob/main/play.html**

> 需要联网（加载 Three.js 3D 引擎）

### 第 2 步：双击打开

下载后 **双击 `play.html`** 即可。

---

## 操作

| 按键 | 作用 |
|------|------|
| **方向键 / WASD** | 移动 |
| **空格 / J** | 撕咬攻击 |
| 比对方大 | 靠近吞食，进化变大 |

**目标：消灭所有恐龙，最后一只存活就赢。**

## 3D 特性

- 第三人称跟随相机
- 3D 恐龙模型（头、尾、腿、血条）
- 草地竞技场 + 树木 + 岩石
- 阴影与雾效
