# 🎱 台球怎么打开

请用 **Chrome** 打开。不要用微信（会白屏）。

GitHub 网页上点文件只能看到代码，那不是游戏。

## 下载后打开（推荐，一直能玩）

点这里下载游戏文件：

👉 **https://github.com/EKW2015/game/releases/download/pool-play-1/pool.html**

1. 用 **Chrome** 打开上面的链接，文件会下载到电脑
2. 找到下载的 `pool.html`
3. **双击** 用 Chrome 打开（Windows 也可双击 `打开台球.bat`）

也可以下压缩包：https://github.com/EKW2015/game/releases/tag/pool-play-1

## 操作

- 按 **4** 开始闯关
- 方向键 / WASD 瞄准和调力道
- **空格** 击打
- 过关按回车
- **M** 打开菜单

## 超能力（进球后获得）

打进球后，下一杆随机得到一个超能力。按 **5** 或点「换能力」可以换成别的：

- **爆发杆**：这一杆打得很用力很用力很用力
- **分身杆**：一次打出三个白球
- **精准清台**：瞄准所有目标球，一杆把它们送进袋

过关后没用掉的超能力会带到下一关。
