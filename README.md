# 🦖 恐龙生存竞技场

## 怎么玩（就 2 步）

### 第 1 步：下载游戏

👉 打开这个网页，点 **Download raw file**（下载）：

**https://github.com/EKW2015/game/blob/main/play.html**

### 第 2 步：双击打开

下载完成后，**双击 `play.html`**，游戏就启动了。

---

## 操作（就 3 个键）

| 按键 | 作用 |
|------|------|
| **方向键** | 移动 |
| **空格** | 攻击 |
| 比对方大 | 靠近就能吃掉 |

**目标：吃掉所有恐龙，最后一只存活就赢。**

---

## 小技巧

- 开局先找**小恐龙**吃
- 遇到大的要**跑**
- 变大了再去打别的
